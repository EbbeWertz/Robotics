# Installed Packages

## Robot Descriptions:
- **ros-jazzy-turtlebot3-description**  
  XACRO-URDF models and meshes voor TurtleBot3.
- **ros-jazzy-open-manipulator-description**  
  XACRO-URDF models en meshes voor OpenManipulator arm.
- **ros-jazzy-xacro**  
  "library" voor XACRO support: Alle built-in URDF files gebruiken XACRO dialect ipv puur URDF.
## Bringups:
- **ros-jazzy-turtlebot3-bringup**  
  Launch files van TurtleBot3 systemen.
- **ros-jazzy-nav2-bringup**  
  Launch files en lifecycle management voor Navigation2 stack.
## Configs:
- **ros-jazzy-turtlebot3-navigation2**  
  Navigation2 config en parameters optimized voor TurtleBot3.
- **ros-jazzy-open-manipulator-moveit-config**  
  Ready-to-use MoveIt configuration voor OpenManipulator.
## Andere:
- **ros-jazzy-webots-ros2**  
  ROS 2 - Webots integration plugin
